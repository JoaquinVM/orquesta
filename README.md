# 🎼 Orquesta

**Dirige un equipo de agentes de IA.** Las tareas no dejan de llegar: dale cada una al agente adecuado antes de que se acumulen.

**▶ Juega aquí: https://joaquinvm.github.io/orquesta/**

*[English below](#english)*

## Cómo se juega

1. Toca una tarea de la bandeja y después un agente para asignársela (o pulsa `1`–`6`).
2. Los **especialistas** trabajan rápido y casi sin bugs. Los demás tardan más y a veces dejan **bugs 🐞** que vuelven a la bandeja.
3. Si una tarea espera demasiado o la bandeja se llena, pierdes reputación ❤️. Con 0, se acaba la partida.
4. En cada nivel eliges una mejora: contratar, formar a un agente, mejores herramientas, revisión automática…

Cuanto más larga tu racha sin errores, más puntos vale cada tarea.

### Modos y progreso

- **📅 Reto diario:** cada día, las mismas tareas para todo el mundo. Compara tu puntuación y mantén tu racha de días.
- **🏅 14 logros** y **7 rangos**, de Becario a Director de orquesta.
- **Resultado para compartir** al estilo Wordle: 🟩 especialista · 🟨 no especialista · 🐞 bug · 🟥 fallo.

## Por qué existe

Trabajo a diario con un sistema de agentes de IA que reparten y revisan trabajo. Este juego es la versión jugable de ese problema: **orquestar bien importa más que tener muchos agentes**.

## Detalles técnicos

- Un solo `index.html`: HTML, CSS y JavaScript sin dependencias ni build.
- Funciona en móvil y en escritorio, en español e inglés.
- El récord se guarda en tu navegador (`localStorage`).
- Publicado con GitHub Pages.

Para jugar en local, abre `index.html` en el navegador.

## English

**Lead a team of AI agents.** Tasks keep pouring in: hand each one to the right agent before they pile up.

**▶ Play: https://joaquinvm.github.io/orquesta/**

### How to play

1. Tap a task in the inbox, then an agent to assign it (or press `1`–`6`).
2. **Specialists** are fast and almost bug-free. Everyone else is slower and sometimes ships **bugs 🐞** that come back to the inbox.
3. If a task waits too long or the inbox overflows, you lose reputation ❤️. At 0, it's game over.
4. Every level you pick an upgrade: hire, train an agent, better tools, automated review…

The longer your streak, the more each task is worth.

**Modes & progress:** a 📅 daily challenge (same tasks for everyone, keep your day streak), 14 achievements, 7 ranks from Intern to Maestro, and a Wordle-style shareable result grid.

### Tech

Single `index.html`, vanilla HTML/CSS/JS, no dependencies, no build step. Mobile-friendly, Spanish and English. Hosted on GitHub Pages.
